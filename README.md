# DrowsyGuard

## Real-Time AI Drowsiness Detection & Alert System

DrowsyGuard is a modular real-time drowsiness detection system designed to detect signs of user fatigue and provide an alert when drowsiness is detected.

## Project Status

🚧 Currently in development

### Current Version

v0.1.0 — Project Foundation

## Planned Features

- Real-time camera monitoring
- Face detection
- Eye detection
- Drowsiness detection
- Real-time alarm system
- Session tracking
- Database storage
- Dashboard
- REST API
- Machine learning-based detection
